# School Website (Studio Demonstration)

## What This Demonstrates

Admissions clarity: structure and trust for parents, with a clean inquiry path and information hierarchy that reduces back-and-forth calls.

## Target Audience

- Parents evaluating the school
- Parents looking for admissions steps and requirements
- Families checking fees/process/timeline basics

## Primary Actions

- Understand programs and fit
- Understand admissions steps
- Submit an inquiry / schedule a visit

## Core Pages / Sections

- Home (positioning + quick facts + admissions CTA)
- Programs / curriculum
- Admissions (steps, timeline, required docs, FAQs)
- Campus life (optional)
- Contact / Inquiry

## Key UX Decisions

- “Admissions” treated as a primary journey, not a footer link.
- Plain, non-marketing language (parents want certainty).
- Mobile-first forms with clear error messages.

## Proof Notes

- Label: Studio Demonstration
- No real school branding or implied affiliation.
