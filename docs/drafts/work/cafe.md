# Cafe Website (Studio Demonstration)

## What This Demonstrates

Local discovery and visit intent: menu clarity, location confidence, and a fast mobile experience.

## Target Audience

- People nearby deciding where to go
- People checking menu/pricing quickly
- People deciding based on vibe/photos/hours

## Primary Actions

- View menu
- Get directions
- Call / reserve (if applicable)

## Core Pages / Sections

- Home (hero + signature items + location)
- Menu (structured categories)
- Gallery (optional, curated)
- Location + hours + contact

## Key UX Decisions

- Menu is first-class (not hidden behind third-party apps).
- Location/hours/call are always reachable.
- Performance-first: fast loading on mobile networks.

## Proof Notes

- Label: Studio Demonstration
- No real cafe branding or claim of operation.
