# Design Inspiration

This folder contains design inspiration and reference materials for the Kivox website.

## MadeByCat Inspiration

MadeByCat is an award-winning digital experience studio specializing in UX/UI design, web development, and digital strategy. Their website exemplifies premium agency design with:

### Key Design Elements to Reference:
- **Sophisticated Typography**: Refined letter-spacing and line-height relationships
- **Premium Spacing**: Thoughtful rhythm and proportional relationships
- **Agency-Level Polish**: Attention to micro-interactions and transitions
- **Visual Hierarchy**: Clear information architecture with refined styling
- **Color Sophistication**: Subtle accent usage and refined color palette

### Design Principles Applied:
- Clean, modern aesthetic with attention to detail
- Professional typography with refined tracking
- Sophisticated spacing and layout systems
- Premium micro-interactions and hover states
- Consistent visual language throughout
